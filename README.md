# BPO COMPANY — Enterprise Website Architecture

A complete, premium, modern, responsive 50-page static website for a generic international **BPO COMPANY** (Business Process Outsourcing, Business Process Management, Customer Experience, Contact Center Services, and Back Office Operations).

Built strictly with **HTML5**, **CSS3**, and **Vanilla JavaScript** without external frameworks, libraries, or backend dependencies. Fully optimized and ready for deployment to **Hostinger static website hosting** or any static web server / CDN.

---

## 1. Project Specifications

- **Identity:** BPO COMPANY (generic enterprise reference architecture).
- **Technology Stack:** Pure HTML5, semantic CSS3, Vanilla ES6+ JavaScript.
- **Styling Architecture:** Custom CSS variables, responsive mobile-first grids, accessible focus rings, and lightweight CSS animations respecting `prefers-reduced-motion`.
- **Pages:** 50 individual, fully coded static HTML pages.
- **Hosting Compatibility:** 100% Hostinger static website hosting compatible (zero build steps, pure static assets).
- **Branding:** Modern navy & blue palette (`#101D35`, `#172B49`, `#2864D8`, `#4D8DFF`, `#21B6A8`) with abstract geometric headset/nodes SVG symbol.
- **Compliance Disclaimers:** Visible disclaimers across all pages ensuring no fabricated historical founding dates, unverified real clients, employee statistics, or unverified certifications (ISO 27001, SOC 2, HIPAA, GDPR, PCI DSS).

## 4. Frontend Interactions & Features

1. **Sticky Header & Mega-Menu:** Sticky navigation bar that smoothly transitions shadow on scroll. The desktop navigation includes a 2-column dropdown menu with icons and subtext linking to all major BPO services.
2. **Mobile Navigation Drawer:** Full-screen responsive drawer menu with accessible touch targets, collapsible dropdown accordion, and body scroll-lock.
3. **Interactive FAQ Accordion (`assets/js/faq.js`):** Smooth expanding and collapsing accordion items with ARIA accessibility tags (`aria-expanded`, keyboard enter/space support).
4. **Interactive Job Search & Filtering (`assets/js/job-search.js`):** Real-time client-side search across job titles and job cards, filtered across Department, Experience Level, and Employment Type with an instant counter and empty state.
5. **Business Consultation Form Validation (`assets/js/forms.js`):** Client-side validation for full name, business email regex, company name, phone format, and required service dropdown. Displays inline error messages and an alert upon demo submission confirming: *"Demo enquiry submitted successfully. No information has been transmitted or stored."*
6. **Demo Job Application with File Validation (`assets/js/forms.js`):** Accepts PDF, DOC, and DOCX resume documents under 5MB. Calculates and displays selected file name and file size in MB with a functional "Clear File" button and drag-and-drop zone.
7. **Back-to-Top Button:** Floating round button that fades in after scrolling 400px and smoothly returns to the top.

## 5. Production Image Assets

All 53 production images generated via Google Flow have been integrated across all 50 website pages:

- **Source Directory:** `images/` (and mirrored in `assets/images/`).
- **File Format:** High-resolution optimized JPEG (`.jpeg`).
- **Styling:** Each image is rendered with `<img src="images/..." class="content-img {ratio}" loading="lazy">`, ensuring zero Cumulative Layout Shift (CLS), subtle elevation shadow, 1px border, and smooth hover interaction.
- **Aspect Ratios Preserved:** Exactly matched to page layout requirements (`16:9`, `4:3`, `21:9`).
- **Prompts & Specifications:** The full generation prompts and camera parameters remain documented in [`IMAGE-GENERATION-GUIDE.md`](./IMAGE-GENERATION-GUIDE.md).
